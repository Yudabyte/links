# yudaNeverLose

Web portofolio (Vite + npm).

## Ubah link
Edit `src/links.js`.

## Jalankan lokal
```
npm install
npm run dev
```

## Tayang di GitHub Pages
1. Push ke repo GitHub (branch `main`).
2. Repo > Settings > Pages > Source: **GitHub Actions**.
3. Tunggu workflow selesai. Link: `https://USERNAME.github.io/NAMA-REPO/`
